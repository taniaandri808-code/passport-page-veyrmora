The passport spread of the Republic of Veymora — an island republic reached only by
sea — for its holder Mara Ilvestrine Okhrey, coastal ferry pilot. Two-page spread
rendered with Pillow: guilloche paper, engraved portrait, bilingual invented-language
fields, storm-transit endorsement, matched arrival/departure visa stamps and an MRZ.

## Run it

```sh
python3 main.py
```

`gen_passport.py` regenerates `entry.png` (1024x1024, deterministic).
